# 一手参考总账与引用规则

本轮检索日期：2026-09-29。规范、upstream实现、研究论文、vendor文档与本项目提案不混为同一证据等级。下面每个稳定ID在所属规划文档中只有一个定义；本页是统一索引，原始报告的不可恢复聊天citation tokens保留原样，不制造token→URL假映射。

## 1. 引用与版本策略

1. 规范以ratified v20260120为架构基线；验证研究中引用main的重构文件用于发现条款，实施前必须映射回批准版本并锁文件hash，不能用草稿无意改变ISA。
2. XiangShan/Difftest/ready-to-run/NEMU用版本闭包，不独立选择各项目latest。已核实的候选SHA见validation-plan；它们仅证明来源关联，不证明编译/ABI/运行成功。
3. latest/动态网页没有固定revision的，记录访问日与已读取范围，并把实施时pin列为gate；不编造SHA。论文arXiv ID/正式出版信息可追溯，但未锁arXiv修订号的不得称严格可复现实验包。
4. 搜索摘要用于找到primary URL。摘要与primary冲突优先采用实际读取内容并保留差异说明；本轮SEAM-V搜索结果1.34×与当前作者摘要1.38×已作此处理。
5. 链接能打开不证明其中所有主张；readme不证明工具运行过，paper结果不证明本项目收益。数值、时序、资源和板测claim必须有其自己的产物。
6. 不复制受限PDF、PDK、license keys、专有IP或第三方大段正文；本仓库跟踪原始用户文档、URL/版本/读取限制与自写审查。后续取得可再分发资料时另记录license、hash、存储位置。

## 4. 新引用的维护动作

新增引用时先读primary相关段落，记录author/title、URL、release/commit/document revision、检索日、支持的具体claim和限制；再为本页/所属账本加入唯一ID。移动网页须同时保留原URL与替代来源关系。更换ISA/tool/reference版本必须触发相应capability/ABI/negative-control回归，而不是只更新链接文字。source-inventory的原文hash禁止随审查意见改变；原文新增版本作为新来源留存。
